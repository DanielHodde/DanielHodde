### About
Software engineer working on cloud operations and resilience at Capital One. I build LLM-based fault localization systems using RAG over telemetry 
and runbooks, and work on an observability data lakehouse handling around a petabyte of telemetry daily on Iceberg, Spark, and EMR.

UC Berkeley grad (dual degree CS + Cognitive Science). Previously interned at AWS and Optum and Early Stage Startup (Viola Walk Home).

Outside of work, I race competitively as a cyclist and built an AI-powered training assistant that pulls from Strava, Apple HealthKit, and intervals.icu, using Claude as the reasoning layer over MCP.

Feel free to reach out over email or linkedin if you have any questions or want to connect.
